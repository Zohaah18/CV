# Computer Vision Lab 02

This repository contains the implementations of the Computer Vision Lab 02 tasks.

## Tasks

### Task 1 - Chest X-Ray Analysis

This task works with a chest X-ray dataset containing:

- COVID-19
- Pneumonia
- Normal

Dataset:
https://www.kaggle.com/datasets/sachinkumar413/covid-pneumonia-normal-chest-xray-images

### Task 2 - CT & MRI Fusion

This task performs analysis/fusion using cardiac CT and MRI images.

Dataset:
https://www.kaggle.com/datasets/ziya07/heart-ct-and-mri-dataset

### Task 3 - Ultrasound Video Analysis

This task performs enhancement and side-by-side monitoring of an echocardiography video.

Dataset:
https://www.kaggle.com/datasets/manojkumarcs28/echonet-dynamic-by-stanford-university
