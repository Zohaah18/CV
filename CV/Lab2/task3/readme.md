# Task 3 - Real-time echocardiogram video analysis

Place a short ultrasound `.mp4` file in `data/`, then run:

```powershell
python realtime_echo.py --video data/echo.mp4
```

Press `q` to stop the live display. Use `--no-display` when running without a graphical desktop. The side-by-side monitoring video and periodic frame screenshots are saved in `output/`.
